# Pastille icon

Source artwork for the Pastille app icon.

- `icon.svg` / `icon.png` — full-colour 1024×1024 icon.
- `icon-monochrome.svg` / `icon-monochrome.png` — pure black themed-icon source on a transparent background.
- Android adaptive-icon vectors live in `app/src/main/res/drawable/` and use the same geometry and palette.
- The Play/Fastlane listing icon is rendered from the same source at 512×512.

Palette:

- deep blue `#0B3A78`
- bright blue `#2F7EF7`
- warm off-white `#FFF8ED`
- red accent `#F04452`
